# Excel Data Analysis

Proyek portofolio Data Analyst — analisis dataset Superstore menggunakan Microsoft Excel.

## Isi
- **VLOOKUP & INDEX-MATCH** — lookup data antar kolom
- **Data Cleaning** — Remove Duplicates, TRIM, Text to Columns
- **Interactive Dashboard** — chart, slicer, KPI card dinamis (SUBTOTAL, GETPIVOTDATA)
- **Data Storytelling** — laporan insight & rekomendasi bisnis 1 halaman (lihat `Insight + Recomendation.pdf`)

## Temuan utama
Category Furniture memiliki profit margin terendah meski volume penjualan tinggi, 
terutama di Region Central & East — memerlukan evaluasi kebijakan diskon.
